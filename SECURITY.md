# Security Policy

## Supported versions

Only the latest release of Anchor Metronome (Android and iPhone) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately via GitHub: **Security → Report a vulnerability** on [DamionGans/Anchor](https://github.com/DamionGans/Anchor/security/advisories/new).

Include the affected version and platform, reproduction steps, and the potential impact. You can expect an initial response within 7 days.

## Scope

Anchor collects no data (see the [privacy policy](https://damiongans.github.io/Anchor/privacy.html)). Its only network access is the GitHub Releases update check in GitHub builds. Store and F-Droid builds make no network requests.
